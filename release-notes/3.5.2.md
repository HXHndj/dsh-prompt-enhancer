# v3.5.2 — 设置界面层级化重构（微调 + 优化参数四级布局）

> 两轮界面打磨合并发布：① 设置导航「提示词增强」去掉 ✨ 前缀改纯文本、模型配置区去掉折叠改为内容常显；② 「优化参数」tab 重构为层级分明的四级布局，风格对齐 DSH 官方设置界面。全部为客户端 UI/样式改动，host RPC 面与配置格式零改动，升级无需迁移配置。

## ✨ 变更

### 设置界面微调

- **导航纯文本**：设置页左侧导航的本插件条目不再带 ✨ 表情（输入框工具行的 ✨ 增强按钮不受影响）
- **模型配置常显**：模型配置区不再有「展开/收起」折叠头，标题与当前模型摘要为静态头部，内容直接可见

### 优化参数四级层级布局

- **L1 分组**：拆为「优化行为 / 记忆与上下文 / 运行参数 / 自定义模板」四组，组间细横线划分，组头带短横线标记
- **L2 字段行**：标签左、控件右的两栏网格；行高与控件宽度有稳定预算，窄面板自动降级为两段式
- **L3 字段说明**：每项的说明文字缩进对齐标签，与标签紧绑定
- **L4 页脚元信息**：「当前模式默认…」移作页脚，灰度更暗一级、段间距最大
- 「优化模式 + 模板」从挤在一行拆为两条独立设置行

## 🔧 兼容性

- host RPC 面与配置 schema 零改动，`protocolVersion` 不变；升级后无需任何配置迁移
- ⚠️ 历史版本注意：v3.4.0 起移除插件内重启（更新后请手动重启 DSH）；v3.5.0 起移除语音识别（BREAKING）。首次从 ≤ v3.4.x 升级请先阅读 [v3.5.0 release notes](3.5.0.md)

## 📦 安装

```sh
dsh plugin --profile web add github:HXHndj/dsh-prompt-enhancer#v3.5.2
```

DSH Desktop 用户：在应用内 侧栏「插件」页 → 添加插件，填入 `github:HXHndj/dsh-prompt-enhancer#v3.5.2`，装完启用并重启客户端。
