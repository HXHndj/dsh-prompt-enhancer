# v3.5.6 — 模式切换入口：单一界面完成所有设置

> ▾ 菜单新增第 4 行「**模式切换**」，点进去即可在 5 个内置模式（基础 / 轻量 / 标准 / 专家 / 一键发布）与你自己配置的自定义模板之间切换——记忆链、增强模型、思考等级、优化模式四项设置现在都能在输入框旁这一个菜单里完成。纯客户端呈现层扩展，配置与 RPC 零改动，升级无需迁移。

## ✨ 新增

- **一级第 4 行「模式切换」**：行内显示当前模式短标签（与输入框 ✨ 后的「基础 / 轻量 / 标准 / 专家 / 发布」同源同文案）+ `›` 下钻；原有三行（记忆链 / 增强模型 / 思考等级）位置与行为不变。
- **二级模式面板**：`‹ 模式切换` 返回头 + 5 个内置模式（行内全称 + `✓` 当前，下钻自动高亮落在正在使用的模式上）。
- **自定义模式一眼可辨**：某个模式若选中了你新建的自定义模板，该行右侧会带出模板名标签——直接选中即切回「你自定义的那套」，无需去设置页翻。

## 🔗 联动

- 切换后**输入框主键标签即时变化**（如切到轻量 → ✨ 轻量），设置页「优化模式」同步；
- 与设置页**同语义**：切换模式同时把该模式的默认档位重置（超时 / Token / 字符 + 上下文预算），从菜单切与从设置页切结果完全一致。

## 🔧 兼容性

- 纯客户端呈现层扩展：host RPC 面与配置 schema 零改动，`protocolVersion` 不变
- ⚠️ 历史版本注意：v3.4.0 起移除插件内重启（更新后请手动重启 DSH）；v3.5.0 起移除语音识别（BREAKING）；v3.5.3 起空输入时主键禁用（记忆开关在 ▾ 菜单里）；v3.5.4 ▾ 菜单改两级下钻；v3.5.5 修复三处对齐并改原生观感开关。首次从旧版升级请先阅读对应版本 release notes

## 📦 安装

```sh
dsh plugin --profile web add github:HXHndj/dsh-prompt-enhancer#v3.5.6
```

DSH Desktop 用户：在应用内 侧栏「插件」页 → 添加插件，填入 `github:HXHndj/dsh-prompt-enhancer#v3.5.6`，装完启用并重启客户端。
