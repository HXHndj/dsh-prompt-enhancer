# v3.5.4 — ▾ 菜单两级下钻

> ▾ 菜单从「一屏挤排全部信息」重构为两级结构：一级只有三行——**记忆开关、模型选择、努力程度**；点模型选择或努力程度下钻到对应二级面板（带返回头与选中 ✓）。数据与写入通道零变化，升级无需迁移配置。

## ✨ 变更

- **一级菜单恒三行**，行内显示当前值：
  - **记忆开关**：点击即开/关切换，不离开一级；
  - **模型选择**：显示当前模型名，点击下钻；
  - **努力程度**：显示当前思考等级，点击下钻（模型不支持推理时置灰）。
- **二级面板**：
  - 模型选择：‹ 返回头 + 按提供方分组的模型列表（与设置页同一配置，✓ 标记当前项）；
  - 努力程度：‹ 返回头 + 当前模型支持的全部思考等级 + 关闭项。
- **下钻交互对齐 DSH 官方约定**：下钻自动落在正在使用的那一行、返回落在打开面板的那一格、Escape 逐级退出（先关二级再关整个菜单）、再点 ▾ 收起并归还焦点。
- 菜单内换模型/等级后，设置页「模型配置」实时同步（同一 `fallback[0]`）。

## 🔧 兼容性

- 纯客户端呈现层重构：host RPC 面与配置 schema 零改动，`protocolVersion` 不变
- ⚠️ 历史版本注意：v3.4.0 起移除插件内重启（更新后请手动重启 DSH）；v3.5.0 起移除语音识别（BREAKING）；v3.5.3 起空输入时主键禁用（记忆开关在 ▾ 菜单里）。首次从旧版升级请先阅读对应版本 release notes

## 📦 安装

```sh
dsh plugin --profile web add github:HXHndj/dsh-prompt-enhancer#v3.5.4
```

DSH Desktop 用户：在应用内 侧栏「插件」页 → 添加插件，填入 `github:HXHndj/dsh-prompt-enhancer#v3.5.4`，装完启用并重启客户端。
