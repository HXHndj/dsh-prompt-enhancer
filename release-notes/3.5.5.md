# v3.5.5 — 三处对齐修复 + 记忆链开关控件

> 修复三处截图指出的对齐/指示问题：▾ 下拉按钮的箭头归位高亮胶囊正中、「撤销优化 / 继续优化」文字回到胶囊正中、▾ 菜单里的「记忆链」开/关由纯文字改为与 DSH 原生一致的开关控件。纯客户端呈现层修复，配置与 RPC 零改动，升级无需迁移。

## 🔧 修复

- **▾ 下拉按钮：箭头居中** — 鼠标悬停时高亮胶囊内的 ▾ 原来偏左约 2.5px（左内边距 2px / 右 6px，且弹性盒未声明居中），现改为左右对称 4/4 + 居中；胶囊总宽（约 20px）与位置不变。
- **「撤销优化」「继续优化」：文字居中** — 这两种纯文字态沿用了主键给 ✨ 图标预留的左 4px / 右 8px 内边距，文字整体偏左约 2px；新增居中类改左右对称 6/6，胶囊总宽（64px）不变，首次优化态（✨ + 模式短标签）不受影响。
- **「记忆链」开/关：文字 → 开关控件** — 值位不再是「开 / 关」两个字，而是一个开关：36×20 胶囊轨道 + 16px 圆形滑块，形态与色板逐项对齐 DSH 原生 Switch（关 = `border-l3`、开 = `brand-primary`、滑块 = `label-primary-foreground`，随主题自动适配）；点击整行即可切换（行为不变，开关本身不抢焦点）。同时修正该行的无障碍语义——现在如实反映开/关状态（此前该行恒报「未选中」）。
