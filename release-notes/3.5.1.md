# v3.5.1 — 模型配置单选化 · 分层卡片布局 · 失败原因分类提示

> 设置 → 提示词增强 → 模型配置：从「模型队列，按顺序逐渐尝试」改为**单选**——只配置一个模型，来源为 DSH 已配置的模型；布局改为逐行分层的卡片式；增强/测试失败时显示具体原因（连接失败、模型不存在、余额不足等）。host 侧 RPC 面与配置格式零改动，升级无需迁移配置。

## ✨ 变更

- **单模型配置**：模型配置栏只保留一个模型，任何选择即写回该模型；「上移/下移」层级调整随队列退役
- **模型来源 = DSH 已配置的模型**：选择器数据取自宿主 `models/list`（各提供方及其模型）+ 内置候选；自定义模型管理能力保留
- **分层卡片布局**：每个信息单元独立成行（提供方 / 模型 / 思考开关与等级 / 操作与测试结果），不再挤在一行
- **失败原因分类提示**：行内「测试」与增强错误条都按错误码显示分类文案——连接失败/超时、模型不存在、密钥或余额不足、空回复、中断取消等，不再是笼统的「增强失败」

## 🔧 兼容性

- **host 侧零改动**：RPC 面与配置 schema 不变（`fallback` 仍为数组，单选 = 长度 1），`protocolVersion` 不变
- **旧多模型配置不丢失**：升级后界面以第一个模型为当前模型，并在检测到旧版多模型队列时显示收敛提示；仅在你下次选择模型时收敛为单模型，不做加载时自动改写
- 首次安装的默认模型继承改为单模型：优先继承你当前正在使用的模型（含推理等级）
- ⚠️ 历史版本注意：v3.4.0 起移除插件内重启（更新后请手动重启 DSH）；v3.5.0 起移除语音识别（BREAKING）。首次从 ≤ v3.4.x 升级的用户请先阅读 [v3.5.0 release notes](3.5.0.md)

## 📦 安装

```sh
dsh plugin --profile web add github:HXHndj/dsh-prompt-enhancer#v3.5.1
```

DSH Desktop 用户：在应用内 侧栏「插件」页 → 添加插件，填入 `github:HXHndj/dsh-prompt-enhancer#v3.5.1`，装完启用并重启客户端。
