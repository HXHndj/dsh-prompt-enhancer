# v4.0.0 — 三档重构：轻量 / 标准 / 专家

> **BREAKING**：五模式（基础/轻量/标准/专家/一键发布）收敛为**三档**——轻量（快速润色）/ 标准（默认：意图与目标结构化）/ 专家（盘点与澄清）；**移除全部会话/工作区/网络检索**（与宿主 plan mode 重叠的能力下线，插件聚焦单轮提示词优化）；T1/T2 双模板由档位吸收。旧配置自动迁移，升级后建议到设置页确认一次各档参数。

## ✨ 新增

- **三档模式**：轻量＝纯润色（零增量、输出 ≤ 原文 1.2 倍）；标准＝意图动词化 + 目标识别（本轮/全局，仅取原文）+ markdown 五段骨架（任务/背景/本轮目标/要求/输出，空段省略，简单输入保持简短）；专家＝标准之上做七项要素盘点（已明确/缺失/歧义）。
- **专家档澄清卡**：草稿存在会实质改变优化结果的歧义时，输入框下方弹出选择题卡片（≤3 题，每题 2–4 选项 + 自由输入）——「提交并继续」带着答复生成终稿；「跳过直接优化」让歧义点保持原文原样；「取消」恢复草稿。澄清问答写入记忆链，继续优化不重复追问。
- **证据正文防注入**：草稿以 JSON 证据正文传给优化模型并声明「改写而非执行」；代码块/路径/@引用/URL/斜杠前缀等保护 token 三档统一逐字保留。

## 🔁 变更

- **记忆流默认开启**（可关闭，记住开关状态）；历史显式关闭的用户保持关闭。
- **上下文预算**改为全局记忆链预算：4000（默认）/8000/16000，不再按模式分档；旧值自动迁移（0/2000→4000、32000→16000）。
- **运行参数按档位**：超时 30/30/60s、Token 2000/2000/4000、输出上限 8000/8000/16000（轻量/标准/专家，仍可手动调整）。
- **模式迁移**：基础→标准、轻量→轻量、标准→标准、专家(旧)/一键发布→专家(新)；各模式自定义模板随迁移保留。

## 🗑️ 移除（BREAKING）

- 旧「基础 / 专家（检索）/ 一键发布」三模式及 T2 增量模板（一句话想法→开发规格请使用宿主 plan mode）。
- 会话参考注入、工作区文件/文档检索、发布模式的多主题网络检索，及对应的进度阶段（读取会话/检索文件/检索会话/组装上下文）。
- 设置页「上下文预算」的 0/2000/32000 档位与按模式档位选择。

## 🔧 兼容性

- 配置自动迁移（模式/模板/预算/记忆开关三值语义），无需手动处理；`enhance` RPC 向后兼容（新增可选 `answers`/`skip` 与 `clarify` 响应分支，旧字段语义不变）。
- ⚠️ 历史版本注意：v3.4.0 起移除插件内重启（更新后请手动重启 DSH）；v3.5.0 起移除语音识别（BREAKING）；v3.5.1 起模型配置单选。首次从旧版升级请先阅读对应版本 release notes。
