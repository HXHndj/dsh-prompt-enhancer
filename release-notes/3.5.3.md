# v3.5.3 — 输入框分裂按钮 + ▾ 增强模型菜单

> 输入框工具行的 ✨ 控件升级为分裂按钮：**主键 = 优化**（点击直接增强，状态机与旧版一致），**▾ = 打开菜单**——记忆开关、增强模型切换（按提供方分组）、思考等级，一处搞定。菜单形态对齐 DSH 官方模型位（圆角、阴影、背景模糊，随主题）。host 侧零改动、零新 RPC，升级无需迁移配置。

## ✨ 变更

- **分裂按钮**：`[✨ 优化] [▾]` 组合体，右侧紧贴 DSH 自己的模型位；主键在有内容时点击即增强，增强中/完成/继续优化的状态文案与旧版完全一致
- **▾ 菜单**：
  - **记忆开关**：首行显示当前开/关，点击即时切换；
  - **增强模型**：按提供方分组列出（数据与设置页「模型配置」同源），当前模型带 ✓，点击切换即写回（两边状态实时同步）；
  - **思考等级**：选中支持推理的模型后出现，可选 高/中/低 或关闭。
- **键盘与焦点**：Escape / 点击外部关闭并归还焦点，↑/↓ 移动、Enter/Tab 选定（基础支持）

## ⚠️ 行为变更（请留意）

- **空输入时主键不再切换记忆**：旧版「输入框无内容时点 ✨ = 切记忆」的隐藏功能移除，改为**禁用置灰**（提示「输入内容后可优化」）；记忆开关现在是 ▾ 菜单里的显性选项。

## 🔧 兼容性

- host RPC 面与配置 schema 零改动，`protocolVersion` 不变；菜单与设置页写同一个模型配置，无需任何迁移
- ⚠️ 历史版本注意：v3.4.0 起移除插件内重启（更新后请手动重启 DSH）；v3.5.0 起移除语音识别（BREAKING）。首次从 ≤ v3.4.x 升级请先阅读 [v3.5.0 release notes](3.5.0.md)

## 📦 安装

```sh
dsh plugin --profile web add github:HXHndj/dsh-prompt-enhancer#v3.5.3
```

DSH Desktop 用户：在应用内 侧栏「插件」页 → 添加插件，填入 `github:HXHndj/dsh-prompt-enhancer#v3.5.3`，装完启用并重启客户端。
