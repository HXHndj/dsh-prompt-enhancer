# v4.1.0 — 记忆流语义修订 · 澄清卡 kind 协议 · 澄清记录入链 · 按钮三态 · 专家档固定记忆

v4.0.x 之后四批用户决策的整体落地：**记忆流按「同一段提示词的迭代会话」重定义边界并持久化**、**澄清卡升级为缺漏/歧义唯一准入口**、**澄清记录跨轮存活**、**「重新优化 / 继续优化」按钮与后端行为同源**、**专家档固定开启记忆流**。配置自动迁移,无 BREAKING。

## 一、记忆流(发送前的多轮迭代优化)

- **清零边界 = 三个触发**:发送消息 / 手动清空输入框 / 切换优化模式——任一发生,记忆链(与澄清记录)一并清零,绝不串入下一段提示词;**刷新页面保留**(按会话持久化,localStorage)。
- **预算档位 8000(默认)/ 16000 / 32000**(旧 0/2000/4000 自动迁移到 8000;32000 不再降级);最多保留**往前三轮**(每轮 = 优化前草稿 + 优化后结果)。
- **注入策略**:当前草稿**永不截断**;历史由近及远**整轮装填**,装不下整轮丢弃最老的;截断按行边界,代码围栏/JSON/路径不被切半,任何情况下不注入空消息。
- **专家档固定开启记忆**:开关仅对轻量/标准档生效;专家档下恒视为开(UI 置灰提示),存储值不覆盖,切回后恢复原设置。

## 二、澄清卡(专家档):缺漏/歧义唯一准入口

- **两类问题**:`gap`(补信息——可给 0–4 个建议选项,或纯自由输入,永远有「保留原句」行)与 `ambiguity`(消歧——2–4 选项 + 自由输入);问题内容、选项、类型全部由优化模型判断生成,一次 1–3 题。
- **跳过 = 保守策略**:「跳过直接优化」= 全部歧义/缺漏点保持原文原样,模型不替你选边。
- **UI 对齐原生 ask-user 卡片形态**(xl 圆角、aria-checked 选项、autosize 输入、header 图标取消);一题未答时提交禁用(零作答不再原地重问)。
- **解析加固**:澄清 JSON 不再被前置代码围栏吞掉;疑似澄清信号解析失败自动重试一次,仍失败明确报错,裸 JSON 绝不会写进你的草稿。

## 三、澄清记录入链(继续优化不重复问)

已答 / 保留原句的记录**随链存活**:澄清出终稿之后的每一次「继续优化」都携带这些记录,模型不再重复追问已答或已保留的点;刷新保留、清链三触发同步清除、撤销优化不回退、澄清卡取消只放弃未提交的题(前轮已答保留)。

## 四、按钮三态:重新优化 / 继续优化

优化成功后:**草稿没改 → 「重新优化」**(从零重跑,不背继续指令,所见即所得);**改过草稿 → 「继续优化」**(注入继续指令与你的修改摘要)。判定与后端 diff 完全同源,不会出现按钮与实际行为打架。首次优化仍是 ✨ + 模式标签。

## 五、三档模板修订(按用户原话逐条校准)

- **标准档**:任何输入都出骨架(删除「简单输入门控」与 800 字符硬上限,改「不冗余、不凑段」);补「本轮目标」真实示例与独立成段规则;删「禁止把疑问升级」「软性语气升格」条款;明确化统一走逻辑重组;稳定性限定为跨次运行确定性。
- **轻量档**:删除 1.2 倍长度上限、语法性补全白名单、疑问不升级;「调整结构」明确限定为语序/用词等表达层。
- **专家档**:结构改为「公共层 + 标准增量 + 专家增量」拼接生成(不再整份复制,杜绝漂移);澄清**始终开启**,无开关;不新增验收标准/非目标/改动摘要段。
