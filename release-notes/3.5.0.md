# v3.5.0 — 剥离语音识别（BREAKING）· 收敛为 ✨ 单功能

> DSH 官方桌面端已内置语音识别，本插件内的重复实现予以剥离——自本版起收敛为**提示词增强（✨）单功能插件**。同时，安装 / 更新事实源迁移至本 fork 仓库（`HXHndj/dsh-prompt-enhancer`），后续更新与维护在本仓库进行。

## ⚠️ 升级注意（BREAKING）

- **语音识别（🎤）功能整体移除**：云端（Qwen3-ASR）/ 本地（SenseVoice）双引擎识别、录音 UI、语音模型管理与本地运行时部署一并下线。
- 对外 RPC 变更：`voice/*` 共 **10 条** RPC（`voice/modelList` · `voice/modelDownload` · `voice/modelProgress` · `voice/modelApply` · `voice/modelOpenDir` · `voice/modelDelete` · `voice/deployRuntime` · `voice/deployStatus` · `voice/status` · `voice/transcribe`）连同 schema 校验全部移除，线上注册面 34 → **24** 条。
- 语音模型下载代理（`download.proxy` 配置）与设置页「语音识别」段落同步移除。
- **✨ 提示词增强完全不受影响**——模型链 / 优化模式 / 参数 / 模板 / 记忆开关等配置无需迁移。
- 如仍需语音输入，请使用 DSH 官方内置的语音识别。

## 🔀 仓库迁移

- 安装 / 更新事实源由原仓库 `Fishsb/dsh-prompt-enhancer` 改指本 fork `HXHndj/dsh-prompt-enhancer`：host 安装命令白名单（`INSTALL_REPO`）、client 更新器默认仓库、设置页项目链接、README 徽章与安装命令均已切换；历史版本（≤ v3.4.0）的发布链接保留原仓库。

## 📦 安装

```sh
dsh plugin --profile web add github:HXHndj/dsh-prompt-enhancer#v3.5.0
```
