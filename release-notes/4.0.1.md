# v4.0.1 — 优化参数设置页对齐官方内置插件页

> 纯前端信息层级与视觉调整：`设置 → 提示词增强 → 优化参数` 的层级划分与整体风格对齐 DSH 官方内置设置页（通用设置页范式）。**无行为变更**——配置读写、RPC 面、模板与记忆流数据流逐字未动，升级后无需重新配置。

## 🎨 界面（设置 → 提示词增强 → 优化参数）

- **层级划分换轨官方范式**：退役两级短横线标记（组标题的 `——` 与字段前的 `—`）与组间粗分隔线，改用官方内置页的做法——**每行一条 `.5px` 发丝细线 + `16px` 行内边距**；分组标题改为官方 `.heading` 档（13px / 半粗 / **无标记**），分组由「组标题 + 末行自身那条细线」表达，不再依赖自创标记元素。
- **说明文字归位左列**：每行左列为「标题（14px）+ 灰色说明（12px）」竖排两行，右侧为控件；说明不再依赖 18px 缩进对齐——该缩进原是为对齐短横线标记而硬编码的数值（标记宽 10px + 间距 8px），已随标记一并退役。左缘由原来的三条（22 / 18 / 18px）收敛为一条。
- **控件改官方样式**：下拉改为**无边框填充式胶囊**（36px 高 / 12px 圆角 / `bg-module-platform` 填充 / 左右各 14px 内边距 / 14px 文字 / 文-箭头间距 12px），宽度随内容自适应、右缘对齐；箭头由 `▾` 字形换成官方 `IconChevronDownOutline` 几何（14×14 / 1px 描边 / 随主题色）的内联 SVG。
- **文本类字段**对齐官方输入框（`.5px` 描边 / 12px 圆角 / 34px 高）；自定义模板编辑区的 18px 缩进归零，模板内容区改为「标签在上、控件在下」的官方纵向字段，按钮与说明贴块尾。
- **灰阶收敛**：页脚提示不再使用「比字段说明更暗一级」的第三档灰，改用同级灰 + 发丝细线分隔，全页灰阶收敛为两档。
- **窄面板**（宽度 < 480px）：行自动折为「左列 + 全宽控件」两段式。
- **影响面**：仅「优化参数」tab。**模型配置 / 插件管理两个 tab 逐项未变**（下拉仍为描边盒、箭头仍为 `▾`）。

## 🔧 兼容性

- **无行为变更**：不涉及 RPC（线上 24 条方法不变）、配置 schema、模板数据、记忆流与增强管线；浏览器 `localStorage` 中的既有配置原样保留。
- 组标题与全部字段文案（含中英双语）逐字未动，语言切换行为不变。

